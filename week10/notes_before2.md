# week09/tools.py 함수 정리

`tools.py`는 영화진흥위원회(KOBIS) 오픈 API로 **일별 박스오피스** 정보를 가져오는 도구 모음이다.

- API 키는 `secret.py`의 `API_KEY`에서 불러온다.
- 요청 주소(`BASE_URL`)는 일별 박스오피스 조회 API(`searchDailyBoxOfficeList.json`)이다.
- 두 함수 모두 `requests.get(BASE_URL, params={"key": API_KEY, "targetDt": date}, timeout=10)`로 요청하고,
  응답 JSON의 `boxOfficeResult` → `dailyBoxOfficeList`에서 영화 목록을 꺼낸다.

## 1. `get_boxoffice_rank_1(date)`

그 날짜의 박스오피스 **1위 영화 제목**을 알려준다.

| 구분 | 내용 |
|------|------|
| 받는 것 | `date` (문자열) - 8자리 날짜. 예: `"20260824"` |
| 돌려주는 것 | (문자열) 1위 영화 제목. 예: `"오디세이"` |

동작: 영화 목록의 첫 번째 항목(`movies[0]`)의 `movieNm`(영화 이름)을 돌려준다.

## 2. `get_movie_audience(date, title)`

그 날짜의 박스오피스 순위에서 영화 제목을 찾아 **일일 관객 수**를 알려준다.

| 구분 | 내용 |
|------|------|
| 받는 것 | `date` (문자열) - 8자리 날짜. 예: `"20260824"` |
|  | `title` (문자열) - 영화 제목. 예: `"오디세이"` |
| 돌려주는 것 | (문자열) 관객 수. 예: `"186,587명"` |
|  | 순위에 없으면 안내 문장. 예: `"'오디세이' 은(는) 20260824 순위에 없습니다."` |

동작:
1. 영화 목록을 하나씩 돌면서 `movieNm`이 `title`과 똑같은 영화를 찾는다.
2. 찾으면 `audiCnt`(관객 수)를 정수로 바꾼 뒤 천 단위 쉼표를 붙여 `"186,587명"` 형태로 돌려준다.
3. 끝까지 못 찾으면 순위에 없다는 안내 문장을 돌려준다.
