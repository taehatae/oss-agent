# week09 tools.py 함수 정리

`week09/tools.py`는 영화진흥위원회(KOBIS) 오픈 API의 **일별 박스오피스** 데이터를 가져오는 도구 모음이다.

## 공통 사항

- API 키는 `secret.py`의 `API_KEY`에서 가져온다.
- 요청 주소(`BASE_URL`): `searchDailyBoxOfficeList.json` (일별 박스오피스 목록)
- 요청 파라미터: `key`(API 키), `targetDt`(조회 날짜, 8자리 `YYYYMMDD`)
- `requests.get(..., timeout=10)`으로 호출하고, 응답 JSON의
  `boxOfficeResult` → `dailyBoxOfficeList`에서 영화 목록을 꺼낸다.

## 함수 목록

### 1. `get_boxoffice_rank_1(date)`

그 날짜의 박스오피스 **1위 영화 제목**을 돌려준다.

| 구분 | 내용 |
|------|------|
| 받는 것 | `date` (문자열) — 8자리 날짜. 예: `"20260824"` |
| 돌려주는 것 | (문자열) 1위 영화 제목. 예: `"오디세이"` |

동작: 영화 목록의 첫 번째 항목(`movies[0]`)의 `movieNm`을 반환한다.

### 2. `get_movie_audience(date, title)`

그 날짜의 박스오피스 순위에서 영화를 찾아 **일일 관객 수**를 돌려준다.

| 구분 | 내용 |
|------|------|
| 받는 것 | `date` (문자열) — 8자리 날짜. 예: `"20260824"`<br>`title` (문자열) — 영화 제목. 예: `"오디세이"` |
| 돌려주는 것 | (문자열) 관객 수. 예: `"186,587명"`<br>순위에 없으면 `"'제목' 은(는) 날짜 순위에 없습니다."` |

동작: 영화 목록을 하나씩 돌며 `movieNm`이 `title`과 **정확히 일치**하는 영화를 찾고,
`audiCnt`를 정수로 바꿔 천 단위 쉼표와 "명"을 붙여 반환한다.

## 참고할 점

- 두 함수 모두 같은 API 호출 코드가 반복된다.
- 오류 처리가 없다: 네트워크 오류, 잘못된 날짜, 빈 목록(`movies[0]`에서 `IndexError`) 등은 그대로 예외가 난다.
- `get_movie_audience`는 제목이 띄어쓰기까지 정확히 같아야 찾는다.
